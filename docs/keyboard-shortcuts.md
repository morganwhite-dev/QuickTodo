# Keyboard shortcuts

These shortcuts are built into QuickToDo. Most also appear in the app's menus.

[Back to the README](../README.md)

## Anywhere on your Mac

| Keys | What it does |
|------|--------------|
| Control + Option + Command + Space | Opens Quick Add from any app |

## Tasks menu

| Keys | What it does |
|------|--------------|
| Command + N | Opens the Detailed Task form |
| Command + F | Searches your tasks |
| Command + D | Marks the selected task done |
| Command + E | Edits the selected task |
| Command + Delete | Deletes the selected task. It goes to Trash |

## Go menu

| Keys | What it does |
|------|--------------|
| Command + 1 | Decision Board |
| Command + 2 | General |
| Command + 3 | Today |
| Command + 4 | Upcoming |
| Command + 5 | Lists |
| Command + 6 | Completed |
| Shift + Command + T | Trash |

## Settings

| Keys | What it does |
|------|--------------|
| Command + comma | Opens Settings |

## Moving through a list

| Where | Keys | What it does |
|-------|------|--------------|
| General, Today, Lists, Completed | Up and Down arrows | Moves between tasks |
| General, Today, Lists, Completed | Space or Return | Ticks the selected task |
| Upcoming | Left and Right arrows | Changes the day |

## Quick Add window

| Keys | What it does |
|------|--------------|
| Return | Adds the task |
| Escape | Closes the window |

Quick Add also appears in the Tasks menu as **Quick Capture**.
